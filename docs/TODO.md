# 미결정 · 나중에 구현할 항목

나중에 정하기로 한 것들을 모아 둔 목록입니다. 정해지면 이 목록에서 지우고 README의 확정 규칙으로 옮깁니다.

## 나중에 구현하기로 한 것
- [ ] **변형 앞/뒤 메커니즘**: 위치에 따라 다르게 동작하도록 바꿀 예정(사용자가 다시 설명 예정). 관통 아이디어: 앞 = 추가 관통 피해, 뒤 = 방어 무시 (방어력 개념 필요). 현재 관통·분열은 앞에만, 유도는 앞뒤 같은 효과.
- [ ] **효과 없는 변형 조합**: 관통·유도·분열을 휘두르기나 폭발에 붙이면 지금은 아무 효과도, 경고도 없음. 효과를 줄지, 경고를 띄울지 결정 필요.
- [ ] **타일 강화 시스템**: 같은 타일을 여러 개 넣어도 효과가 합산되지 않음(강화로 대체 예정).
- [ ] **조건 타일 강화**: `적중 시` 등이 뒤의 타일 2개를 발동하는 강화 (`RuleCompiler.DEFAULT_TRIGGER_REACH`).
- [ ] **무한 연쇄 업그레이드**: 조건으로 발동된 행동도 다시 조건을 발동 (`RuleCompiler.DEFAULT_MAX_CHAIN_DEPTH = -1`).
- [ ] **타일 합성**: 2개 → 복합 타일 1개. 합성 가능 조합, 비용, 합성 장소(상점?), 특별 효과 조합 미정.
- [ ] **체력 회복 수단**: 흡혈, 체력 물약 등 (현재 웨이브 사이 체력 유지, 회복 없음).
- [ ] **공격 속도 능력치**: 행동 쿨다운(현재 1.5초)을 줄이는 능력치.
- [ ] **상점 등급·확률**: 현재 11종 완전 무작위 진열.
