# New Game

뱀서라이크 + 로그라이크 + 행동 프로그래밍. Godot 4.7.2 / GDScript / 2D 탑다운 / 1920×1080.

## 실행
Godot 4.7.2에서 `project.godot`을 열고 F5를 누릅니다. 이동은 WASD입니다.

## 확정 규칙 (현재 구현 범위)
- 플레이어는 이동만 직접 조작하고, 공격은 자동으로 합니다.
- 플레이어 능력치는 체력 100, 이동 속도 300px/s입니다. 뱀서라이크 일반값으로 넣은 임시값이고 `scenes/player.tscn` 인스펙터에서 바꿀 수 있습니다.
- 체력이 0이 되면 결과 화면(도달 웨이브)을 띄우고, 버튼을 누르면 새 판을 시작합니다.
- 행동 수칙은 5슬롯 고정이며 빈 슬롯을 허용합니다. 빈 슬롯은 없는 것처럼 건너뜁니다.

### 행동 수칙 해석 (`scripts/core/rule_compiler.gd`)
- 왼쪽 → 오른쪽으로 해석합니다.
- **속성**은 행동 바로 앞에 붙습니다. 연속된 속성은 모두 적용됩니다. 예: `화염 빙결 사격`
- **변형**은 행동 바로 앞이나 뒤에 붙습니다. 예: `관통 사격`, `사격 관통`
  - **분열**은 행동 앞에만 놓을 수 있습니다(여러 발 발사). `적중 시` 뒤에 두면 맞은 뒤 파편으로 갈라집니다. 행동 뒤에 두면 경고합니다.
- **조건**은 바로 앞 행동에만 적용되고, 뒤의 타일 1개를 발동합니다 (강화 시 2개 예정).
  - 뒤가 행동이면 조건 전용이 되어 순차 실행에서 빠지고, 쿨다운 없이 적 위치에서 발동합니다.
  - 뒤가 속성이면 적중한 적에게 상태이상을 겁니다.
  - 뒤가 분열이면 맞은 적 위치에서 파편이 사방으로 퍼집니다.
  - 예: `사격 적중 시 폭발 유도` → 유도는 적용되지 않습니다.
- **무한 연쇄 방지 (A안)**: 조건으로 발동된 행동은 다시 조건을 발동하지 않습니다. 업그레이드로 해제할 수 있도록 `max_chain_depth` 값으로 만들어 두었습니다.
- 잘못된 배치는 허용하지만, 해당 슬롯을 빨간 테두리로 표시하고 경고 문구를 보여 줍니다. 그 타일은 효과 없이 무시됩니다.

### 실행 (`scripts/core/rule_runner.gd`)
- 순차 행동을 왼쪽부터 하나씩 실행합니다. 행동 하나를 실행할 때마다 3초를 기다린 뒤 다음 행동으로 넘어가고, 마지막 행동 다음에는 처음으로 돌아갑니다.
- 폭발을 순차 행동으로 쓰면 플레이어를 중심으로, 조건으로 발동되면 적을 중심으로 터집니다.
- 공격 생성과 적중 처리는 `scripts/combat/combat_system.gd`에서 합니다.
- 같은 타일을 여러 개 붙이면 효과가 합산됩니다 (예: `화염 화염 사격` = 화염 2중첩).
- 지속 피해(화염·독)로 죽은 적은 `처치 시`를 발동하지 않습니다.

### 타일 수치 (임시값, 뱀서류 일반값 기준)
모든 값은 `data/tiles/*.tres` 인스펙터의 "수치 (임시값)" 그룹에서 바꿀 수 있습니다.

| 타일 | 효과 | 임시값 |
|---|---|---|
| 사격 | 가장 가까운 적에게 투사체. 적이 없으면 이동 방향 | 피해 15, 속도 700, 사거리 900, 탄 반경 8 |
| 휘두르기 | 이동 방향 부채꼴 | 피해 20, 반경 150, 각도 120° |
| 폭발 | 원형 범위 (순차: 플레이어 중심, 조건: 적 중심) | 피해 25, 반경 120 |
| 화염 | 지속 피해. 다시 걸면 시간 갱신 (중첩 없음) | 초당 5, 3초 |
| 독 | 중첩되는 지속 피해 | 중첩당 초당 3, 5초, 최대 5중첩 |
| 빙결 | 맞을 때마다 둔화 누적, 100%면 정지 | 1회 25% 둔화, 둔화 유지 2초, 정지 1.5초 |
| 관통 | 투사체가 적을 추가로 관통 | +2 |
| 분열 | 앞: 동시 발사 / 적중 시 뒤: 파편 | 3발 30° 간격 / 파편 3개, 피해 50%, 속도 600, 사거리 300 |
| 유도 | 투사체가 가까운 적을 따라감 | 초당 5라디안 회전 |

### 게임 흐름
시작 화면에서 행동 타일 1개 선택 → 웨이브 → 상점 → 다음 웨이브 → … → 사망 시 결과 화면

### 웨이브 (`scripts/combat/wave_director.gd`, 수치는 인스펙터에서 조정)
- 웨이브마다 정해진 수의 적을 모두 처치하면 끝납니다. 목표 = 10 + 5×(웨이브−1)
- 목표 수만큼만 생성되며, 생성 간격은 1.5초에서 웨이브마다 0.1초씩 줄어듭니다(최소 0.3초).
- 적 체력은 웨이브마다 15%씩 늘어납니다.
- 웨이브가 시작될 때 체력이 가득 찹니다. (임시)
- 적: 플레이어에게 직진하는 근접형 1종. 체력 15, 속도 120, 접촉 피해 10. 플레이어는 피격 후 0.5초 무적입니다.

### 화폐 · 상점 (`scripts/core/shop.gd`, `scripts/ui/shop_screen.gd`)
- 적이 죽은 자리에 코인 1개가 떨어집니다. 150px 안에 들어가면 끌려와서 획득됩니다. 웨이브가 끝날 때 남은 코인은 자동으로 획득됩니다.
- 상점에는 타일 4개가 무작위로 진열됩니다. 가격: 행동 6, 속성 4, 변형 5, 조건 7 (각 `.tres`의 `price`)
- 새로고침 비용은 2이고, 같은 상점에서 할 때마다 1씩 오릅니다.
- 구매한 타일은 보관함(8칸)으로 들어갑니다.
- 끌어다 놓기: 보관함 → 슬롯(배치, 원래 있던 타일은 보관함으로), 슬롯 ↔ 슬롯(순서 변경), 슬롯 → 보관함(회수), 판매 칸(구매가의 절반)
- 상점 화면에서도 잘못된 배치는 빨간 테두리와 경고 문구로 표시됩니다.

### 테스트용 설정
`scenes/main.tscn`의 `Main` 노드:
- `Debug Start Tiles`: 넣으면 시작 화면을 건너뛰고 그 타일들을 슬롯에 넣은 채로 시작합니다.
- `Debug Start Coins`: 시작 코인을 지급합니다. 상점을 시험할 때 쓰세요.

## 구조
| 경로 | 내용 |
|---|---|
| `data/tiles/*.tres` | 타일 정의 (기획서 11종: 이름·종류만 있음). 새 타일은 파일만 추가하면 자동으로 불러옵니다. |
| `scripts/tiles/behavior_tile.gd` | 타일 리소스 (행동/속성/변형/조건, 아이콘) |
| `scripts/tiles/tile_library.gd` | 오토로드: 타일을 id로 조회 |
| `scripts/core/behavior_rule.gd` | 5슬롯 행동 수칙 데이터 |
| `scripts/core/run_state.gd` | 오토로드: 한 판 동안 유지되는 상태 |
| `scripts/visual/shape_visual.gd` | 임시 도형 표시. `texture`를 지정하면 이미지로 바뀝니다. |
| `scenes/` | 메인, 플레이어, HUD 씬 |

## 아트 교체
- 캐릭터: 해당 씬의 `Visual` 노드에서 `texture`를 지정합니다.
- 타일: `.tres`의 `icon`을 지정합니다.
